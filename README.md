# 하루 · 2026 캘린더

2026년 날짜별로 할 일을 기록하는 개인용 달력 앱입니다. HTML, CSS, JavaScript로 구현했으며 별도 설치나 빌드 없이 사용할 수 있습니다.

## 실행 방법

1. `dist` 폴더를 엽니다.
2. `index.html`을 Chrome, Edge 등 웹 브라우저로 엽니다.
3. 달력에서 날짜를 선택하고 오른쪽 입력창에 할 일을 입력합니다.

`index.html`, `style.css`, `app.js`는 같은 폴더에 유지해야 합니다. 프리텐다드 폰트는 외부 CDN에서 불러오므로 인터넷 연결이 필요합니다. 폰트를 불러오지 못하면 시스템 폰트로 표시됩니다.

## 주요 기능

- 2026년 1월부터 12월까지 월별 달력 탐색
- 날짜별 할 일 추가, 완료 표시, 삭제
- 날짜별 할 일 미리보기 및 추가 항목 수 표시
- 완료한 할 일 수에 따른 달성률 표시
- 오늘 날짜로 이동
- 브라우저에 할 일 자동 저장
- 데스크톱과 모바일 화면에 대응하는 반응형 레이아웃

## 사용 방법

1. 왼쪽 월 선택 버튼이나 달력 위 화살표로 원하는 달을 선택합니다.
2. 달력의 날짜를 클릭합니다.
3. 할 일을 입력한 뒤 `+` 버튼을 누르거나 Enter 키를 누릅니다.
4. 항목 옆 체크박스를 선택하면 완료 처리됩니다. 다시 선택하면 완료가 해제됩니다.
5. 항목 오른쪽 `×` 버튼을 누르면 해당 할 일이 즉시 삭제됩니다.

할 일은 최대 150자까지 입력할 수 있으며, 공백만 입력한 항목은 추가되지 않습니다. 삭제 취소 기능은 없습니다.

기기 날짜가 2026년이면 오늘 날짜부터 열립니다. 다른 연도이면 2026년 1월 1일부터 열리며, '오늘로 이동' 버튼은 비활성화됩니다.

## 파일 구성

```text
웹페이지/
├── README.md              # 프로젝트 안내
├── dist/
│   ├── index.html         # 화면 구조 및 폰트 연결
│   ├── style.css          # 색상, 레이아웃, 반응형 스타일
│   └── app.js             # 달력, 할 일 관리, 자동 저장
└── .openai/
    └── hosting.json       # Sites 배포용 설정
```

로컬 실행에는 `dist` 폴더의 세 파일만 필요합니다. 배포 설정 파일이 있어도 온라인 배포가 완료되었다는 의미는 아닙니다.

## 데이터 저장

할 일은 서버로 전송하지 않고 브라우저의 `localStorage`에 저장합니다.

- 저장 키: `haru-calendar-2026-v1`
- 날짜 키 형식: `2026-MM-DD`
- 항목 속성: 고유 ID(`id`), 내용(`text`), 완료 여부(`done`)

```json
{
  "2026-09-13": [
    {
      "id": "example-task-id",
      "text": "책 20쪽 읽기",
      "done": false
    }
  ]
}
```

같은 브라우저와 같은 실행 위치에서 다시 열면 저장된 할 일을 복원합니다. 다른 기기나 브라우저와 자동으로 동기화되지 않습니다. 브라우저 데이터를 삭제하면 할 일도 사라질 수 있으며, 시크릿 모드나 저장소 접근 제한 환경에서는 영구 저장이 보장되지 않습니다.

로컬 파일을 직접 여는 방식은 브라우저마다 저장소 동작이 다를 수 있습니다. 파일 위치를 바꾸거나 웹 주소로 실행 방식을 바꾸면 기존 데이터가 표시되지 않을 수 있습니다. 저장에 실패하면 앱 아래에 안내가 표시됩니다.

## 수정 방법

- 색상: `dist/style.css`의 `:root` 변수 수정
- 문구 및 화면 구조: `dist/index.html` 수정
- 달력과 할 일 동작: `dist/app.js` 수정

수정한 뒤 브라우저를 새로고침하면 반영됩니다. 연도는 2026년 전용이며, 다른 연도로 확장하려면 날짜 로직뿐 아니라 저장 키, 데이터 검증, 화면 문구도 함께 수정해야 합니다.

## 확인한 항목

JavaScript 문법 검사와 모의 DOM 기반 동작 검증을 수행했습니다.

- 12개월 표시와 연도 경계 이동 제한
- 2026년 2월의 날짜 수
- 할 일 추가 및 공백 입력 방지
- 재실행 시 저장 데이터 복원
- 완료 표시 및 달성률 갱신
- 할 일 삭제

실제 브라우저에서의 시각적 검증과 모든 기기·브라우저 조합에 대한 검증은 수행하지 않았습니다.
